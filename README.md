# TP-ML-avancé

A la fin de ce module l'étudiant sera capable de: 
- Identifier expliquer les concepts clés du machine Learning
- Différencier les principales phases d’un projet machine Learning
- Préparer les données en utilisant les différentes librairies Python.
- Analyser, créer et évaluer des modèles linéaires. Appliquer et évaluer des méthodes basées sur des relations géométriques entre les données
